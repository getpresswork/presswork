# Contribute to Presswork

Thank you for your help.

Before you start, read these chapters:

- [Workflow](docs/src/contributing/workflow.md)
- [Style guide](docs/src/contributing/style-guide.md)
- [Code style](docs/src/contributing/code-style.md)

These are the main rules:

1. Use test-driven development. First, write a test that fails.
2. Turn on the Git hooks with `git config core.hooksPath .githooks`.
3. Write each commit message on one line, in the Conventional Commits form.
4. Write all text in ASD-STE100 Simplified Technical English.

Each contribution is available under the Apache License 2.0, as section 5 of the [license](LICENSE) tells.
