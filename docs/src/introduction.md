# Presswork

Presswork is a typesetting and publication workbench. It uses [Typst](https://typst.app) as its typesetting engine.

Presswork has two parts:

- A desktop application for Windows, Linux, and macOS. You use it to write, typeset, review, and export publications.
- A server for publishing teams. The server keeps shared projects, roles, issues, tasks, checklists, routines, and reports.

The desktop application operates without a server. When you connect it to a server, your team can edit the same documents at the same time.

> **Status:** Presswork is in early development. It is not ready for production work.

## About this book

This book has two parts:

- **Design** tells how Presswork operates and why.
- **For contributors** tells how to work on Presswork.
