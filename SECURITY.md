# Security policy

## Report a vulnerability

Do not report a security problem in a public issue.

Use the private vulnerability report of GitHub:

1. Open the **Security** tab of the repository.
2. Select **Report a vulnerability**.
3. Write the problem, the steps that cause it, and the affected versions.

The maintainers reply in 7 days or less. They tell you the result of their examination and the plan for a correction.

## Versions that get corrections

Presswork is in early development. Only the last release gets security corrections.
